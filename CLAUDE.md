# Notes for Claude sessions

## NEXT.md — what's waiting on Mark (every project, every session)

Mark keeps one list across all his projects: on Monday mornings his hub's
session reads every repo's `NEXT.md` and tells him what needs doing (3 Oct
2026). So **before you finish any turn where something changed, update
`NEXT.md` at the root of this repo** — short, plain English, newest first:

- **Waiting on Mark** — each thing only he can do or decide, one line each,
  with the date it started waiting and a link if there is one.
- **Waiting on someone else** — Rory, James, a customer, Google… and for what.
- **Next up** — what the next session would do, in order.
- **Updated** — today's date and this session's title.

Take out anything that's done. Never put secrets, keys, customer names or
personal details in it. Commit it with the work; if a turn changed nothing
else, a commit of `NEXT.md` alone is fine.
